# okoriechinonso1.github.io

Personal academic website of Chinonso Okorie.

## Publish on GitHub Pages
1. Create a public GitHub repo named exactly `okoriechinonso1.github.io`.
2. Upload everything in this folder (keep the `images` folder).
3. Settings → Pages → Source: "Deploy from a branch", Branch: `main`, folder `/ (root)` → Save.
4. Visit https://okoriechinonso1.github.io after 1–2 minutes.

## Updating
- Edit text in `index.html` directly on GitHub (pencil icon) and commit.
- Replace `Chinonso_Okorie_CV.pdf` with a new file of the same name to update your CV.
- Replace `images/profile.jpg` to change your photo (4:5 portrait works best).
